# Curso Básico de SQL com Databricks

Curso gratuito de SQL utilizando Databricks e dados públicos de viagens do Governo Federal.

## Aulas

01. Preparação do ambiente
02. SELECT, DISTINCT, LIMIT e ORDER BY
03. Filtrando dados com WHERE
04. IN, BETWEEN e LIKE
05. NULL e tratamento de valores ausentes
06. Cálculos e aliases
07. Funções de texto
08. Funções de data
09. COUNT, SUM, AVG, MIN e MAX
10. GROUP BY
11. HAVING
12. CASE WHEN
13. CTEs
14. Projeto final

## Tecnologias

- SQL
- Databricks
- Git
- GitHub

## Dataset

Dados públicos de viagens do Governo Federal.
